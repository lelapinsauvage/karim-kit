# karim-kit

Personal creative-dev kit. Generic modules, no brief-specific assets.

```bash
npm install && npm run dev
```

| page | what |
|---|---|
| `/sun.html` | a body of light — two colours and a formula |
| `/field.html` | woven pattern field, built in registers |
| `/index.html` | four-look slider, halo-driven transition |
| `/hero.html` | layout and type pass |

- `src/gl.js` — WebGL2 fullscreen-quad harness
- `src/shaders/` — the modules

`CLAUDE.md` carries the conventions, `MECHANISMS.md` the reasoning behind each
effect, `PRINCIPLES.md` the house style.

## Not in this repo

Trial fonts (licensing) and generated imagery (brief-specific). Both are
gitignored; drop your own into `public/fonts/` and `src/figures/`.
