# The live script

One instruction at a time. Each one produces a single thing with controls, then
stops. You set the values between them. Nobody sees a finished page arrive.

**Before minute 0** — fire the image agent in its own session. It writes PNGs and
touches nothing else, so it is the only thing that can run in parallel. The build
agent works one file at a time; a second agent in there is a merge conflict, not
a speed-up.

**0 · Orient** *(paste once)*

> Read karim-kit/START.md. Only that file. Import @karimsaab/kit — don't rebuild
> anything it has. Build one thing at a time and stop after each. I set the
> values; you wire the mechanism and expose it on the panel.

**1 · The canvas** — 60s

> Full-bleed canvas from the kit's `quad`. Flat ground, one colour. Nothing else.

*You:* pick the ground.

**2 · The body** — 90s

> Add the light body from the kit's shader. Sliders for radius, edge, core
> position, glow, rim, spread, warmth, purity. Neutral defaults, don't tune it.

*You:* dial the pigment and every value. **This is the most watchable stretch of
the whole battle — do it slowly and out loud.**

**3 · The figure** — 60s

> Composite the cutout in the shader, bottom-anchored, framed to its alpha
> bounding box. Sliders for height, x, bleed, darken, tint.

*You:* place her. Say why the bottom bleeds.

**4 · The field** — 90s

> Add the Truchet field to the ground. Sliders for opacity, scale, family, morph,
> weight.

*You:* set the density. Name it as Kuba structure, not decoration.

**5 · The wordmark** — 2 min

> Rasterise a wordmark to a canvas texture and sample it in the shader BEFORE the
> figure composite, so she occludes it. Position and size as numbers I can change.

*You:* the word, the scale, where it breaks.

**6 · The record** — 3 min

> Left-ranged data block. Mono, semibold labels, regular values. Four rows.

*You:* write every row. The provenance is the concept.

**7 · The frame** — 3 min

> Top row: lot number left, brand mark centred, nav right, all on one optical
> line.

**8 · The switch** — 4 min

> Second look. Tween every value between two presets, pigment in HSV so it
> travels round the hue circle instead of through grey.

*You:* the second pigment and its record.

**9 · The loader** — 4 min *(cut this first if behind)*

> Two masses accelerating together on real decode progress. Contact triggers the
> reveal. No pause between them.

**10 · Stop at 28.** Scroll it. Say what it is in ninety seconds.

## Rules for you, live

- **Never ask for two things in one instruction.** You cannot tell which half is
  wrong, and untangling costs more than the second instruction would have.
- **Never accept a layout you did not ask for.** If it arrives with type you did
  not specify, that is your minutes gone. Say "remove the layout, keep the
  mechanism."
- **Set every value yourself**, even where the default is fine. Dragging is the
  performance; it is also the proof.
- **Judge by watching.** Change one number, look. Do not describe motion.
- **If a fix changes nothing, check it applied** before theorising about why.
